# MCbotv1 UI Design Context

## Product
MCbotv1 is a desktop Minecraft bot control application built with Electron and a renderer using HTML/CSS/JavaScript.

## Audience
The primary user is the operator/developer who manages Minecraft bots and needs a clear desktop control surface.

## Use cases
- See bot fleet status quickly.
- Connect/disconnect/control bots.
- Inspect a bot in detail.
- Start/pause/stop existing modes.
- Diagnose warnings, errors, incidents and runtime state.
- Adjust existing configuration exposed by the current application.

## Design intent
- Windows 10-like desktop utility.
- Simple, compact, familiar, practical.
- Clear status hierarchy.
- Prefer plain controls and readable information over decorative effects.
- No marketing/landing-page aesthetic.
- Dev UI can be information-dense because diagnosis is a core use case.

## Technical constraints
- Preserve the current Electron + HTML/CSS/JS renderer architecture.
- Treat the current Git code as the source of truth.
- Do not invent features, data or pages.
- Do not replace the renderer with React, Vue, Tailwind or a component framework for visual work.
- Reuse current DOM IDs/classes and data contracts unless a task explicitly requires structural change.
